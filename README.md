# まなびログ

自分用の学習記録アプリ。1日1行、10秒で記録して、続いているのが一目で見える。

**公開URL:** https://ytsuki1970.github.io/manabi-log/

## 特長

- 1ファイルHTML・サーバー不要・完全オフライン（データは端末内の IndexedDB に保存）
- カテゴリ（項目）はアプリ内の「項目を編集」から自由に追加・削除（例：法律・数学・英語）
- 連続日数・今週の合計時間・3か月ヒートマップ・週の目標バー・カテゴリ別割合を自動集計
- JSONバックアップの書き出し／読み込みで端末移行も安心
- ダークモード対応

## 使い方

`index.html` をブラウザで開くだけ。スマホはホーム画面に追加して使うと便利。
